# STM32H743ZIT6 引脚与排针精华笔记

> 资料来源：`datasheet.pdf`（STM32H742/743 datasheet，DS12110 Rev 11）和 `schematic.pdf`（NUCLEO 144 H7 LEGACY / MB1364 / H743ZI 原理图）。

## 1. 先看结论

- **STM32H743ZIT6 的 Z = 144 pins，T = LQFP 封装**，所以开发时主要看数据手册里的 **LQFP144** 列。
- 数据手册里最重要的是 **Table 9 Pin/ball definition**：它把 `LQFP144物理脚号 → STM32引脚名 → 可复用功能` 对起来。
- 原理图里最重要的是 **Sheet 5 Connectors**：它把 `开发板排针编号 → STM32引脚 → 板上功能标号` 对起来。
- 开发时优先查下面两个表：先查“排针速查表”确定你接到哪个 MCU 引脚，再查“LQFP144复用功能表”确定该引脚能不能做 UART/SPI/I2C/ADC/PWM 等。

## 3. 板载资源占用/容易踩坑的引脚

| STM32引脚 | 相关功能 | 板载资源 | 是否被占用 | 开发注意事项 |
|---|---|---|---|---|
| PA13 | SWDIO/JTMS | 调试下载接口 | 是 | 如果关掉SWD/JTAG功能，后续下载调试会麻烦，初学不要占用 |
| PA14 | SWCLK/JTCK | 调试下载接口 | 是 | 同上 |
| PB3 | SWO/JTDO / SPI_B_SCK(D23) | 调试跟踪SWO，同时在CN7-15引出 | 可能 | 不用SWO时可做普通IO/SPI；用调试跟踪时避开 |
| PA15 | JTDI / I2S_B_WS(D20) | JTAG相关，同时在CN7-9引出 | 可能 | SWD模式通常可释放，但JTAG调试时会占用 |
| PD8 | USART3_TX / ST-LINK VCP_TX | ST-LINK虚拟串口 | 是/可能 | 作为板载USB虚拟串口时会被占用 |
| PD9 | USART3_RX / ST-LINK VCP_RX | ST-LINK虚拟串口 | 是/可能 | 作为板载USB虚拟串口时会被占用 |
| PA9 | OTG_FS_VBUS / USART1_TX | USB FS VBUS检测 | 是/可能 | 启用USB FS时占用 |
| PA10 | OTG_FS_ID / USART1_RX | USB FS ID | 是/可能 | 启用USB OTG时占用 |
| PA11 | OTG_FS_DM | USB FS D- | 是/可能 | 启用USB FS时占用 |
| PA12 | OTG_FS_DP | USB FS D+ | 是/可能 | 启用USB FS时占用 |
| PG6 | USB_FS_PWR_EN / QSPI_CS(D26) | USB供电控制 | 可能 | 若启用USB供电开关控制需避开 |
| PG7 | USB_FS_OVCR | USB过流检测 | 可能 | 若启用USB过流检测需避开 |
| PC13 | USER_BUTTON / WKUP | 用户按键 | 是 | 做按键输入可直接用；做普通IO会被按键电路影响 |
| PE1 | USER_LED2 | 板载黄灯LD2 | 是 | 可直接用作LED输出 |
| PB14 | USER_LED3 | 板载红灯LD3 | 是 | 可直接用作LED输出 |
| PA5/PB0 | ARD_D13_LED备选通道 | 板载绿灯LD1/Arduino D13相关 | 可能 | 看SB47/SB39等焊桥配置 |
| PC14/PC15 | OSC32_IN/OUT | LSE 32.768kHz晶振相关 | 可能 | 启用外部LSE时不要当GPIO |
| PH0/PH1 | OSC_IN/OUT | HSE/MCO相关 | 可能 | 用外部高速时钟/晶振时不要当GPIO |
| PB12/PB13/PG11/PG12/PC4/PC5/PA1/PA2/PA7/PC1 | RMII/MII Ethernet | 以太网PHY | 可能 | 启用板载以太网时，这组引脚基本被占用 |

## 5. 快速使用方法

1. **先看原理图排针表**：比如你接到了 CN7-2，查到是 `PB8`，板上标注 `I2C_A_SCL / D15 / SCL`。
2. **再查 LQFP144复用功能表**：看 `PB8` 是否支持你想用的外设，例如 I2C、TIM、UART 等。
3. **再看是否被板载资源占用**：如果该脚被 USB、以太网、ST-LINK、LED、按键、晶振占用，就要么换脚，要么确认焊桥/外设配置。
4. **最后在 CubeMX/Keil 里配置**：同一个引脚同一时刻只能选择一个复用功能，不能又做 UART 又做 SPI。

## 6. 初学开发优先避开的引脚

- 下载调试：`PA13/PA14`，以及可能关联的 `PB3/PA15`。
- USB FS：`PA9/PA10/PA11/PA12/PG6/PG7`。
- 以太网：`PA1/PA2/PA7/PB12/PB13/PC1/PC4/PC5/PG11/PG12` 等。
- 时钟：`PC14/PC15`、`PH0/PH1`。
- 板载按键/LED：`PC13/PE1/PB14/PA5/PB0`。
